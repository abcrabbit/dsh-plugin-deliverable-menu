# 交付物悬浮菜单

为回复正文中的文件链接、行内文件名引用以及交付文件卡片增加悬浮菜单：用系统默认程序打开、打开所在文件夹、复制文件、复制完整路径。

Adds a hover menu to conversation file links and delivered-file cards: open with the default program, show the containing folder, copy the file, or copy its full path.

## 安装

**方式一（推荐）**：在 DSH 插件的「发现」页添加索引源

```
https://raw.githubusercontent.com/abcrabbit/dsh-plugin-index/main/index.json
```

然后搜索并安装本插件。

**方式二（手动）**：下载本仓库，在 DSH「设置 → 插件 → 添加插件 → 本地目录」中选择本目录。
